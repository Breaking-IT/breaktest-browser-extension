# Store assets

These files are uploaded separately in the Chrome Web Store, Microsoft Edge
Add-ons, and Firefox Add-ons dashboards. They are not included in extension
ZIP packages.

Place clean 1280x800 PNG or JPEG captures in `screenshots/`. Use descriptive,
ordered filenames such as:

- `01-start-recorder.png`
- `02-live-recording.png`
- `03-named-transactions.png`
- `04-save-har.png`

Place promotional artwork in `promotional/`:

- `small-440x280.png` for the Chrome/Edge small promotional tile
- `marquee-1400x560.png` for the optional Chrome marquee tile

Do not include customer domains, credentials, cookies, tokens, or real HAR
content in any store image.
