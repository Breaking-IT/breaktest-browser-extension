# Security Policy

## Reporting a vulnerability

Please report suspected BreakTest Browser Recorder vulnerabilities privately
through GitHub's private vulnerability reporting:

1. Open <https://github.com/Breaking-IT/breaktest-browser-extension/security/advisories/new>
   (or choose **Security > Report a vulnerability** on the repository page).
2. Describe the issue, the affected browser and extension version, and
   reproduction steps.

Reports go directly and privately to the maintainers, who will respond
through the advisory thread. Do not open a public GitHub issue or pull
request for an undisclosed security report. If you cannot use GitHub, contact
Breaking IT at <info@breakingit.nl> and request a secure reporting channel.

Do not include a HAR file containing credentials, cookies, tokens, or
personal data in a report. Reproduce the issue against a test system first,
or redact the recording.

## Scope notes

Record only systems you are authorized to test. HAR recordings can contain
credentials, cookies, authorization tokens, personal data, and response
content, and should be reviewed before they are shared.
